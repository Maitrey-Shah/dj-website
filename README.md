### Why I structured it this way

I would **not** make the first Lovable build unnecessarily huge. With your 4% credit limit, the important thing is to get the **design system + homepage + reusable event architecture + WhatsApp conversion** right first.

The reference research also supports making **Events/Tickets the core of the site**, rather than treating the website like a normal company portfolio. Nazaara prominently surfaces upcoming shows and ticket CTAs, while Desi Nights uses event-specific pages with venue, music style, VIP information and ticket urgency. ([Nazaara][1])

For the ticketing architecture, I'd keep the ticket URL configurable rather than building a complicated payment system immediately; Canadian event organizers commonly use external ticketing platforms such as Eventbrite, Showpass, Ticket Tailor and others. ([eventist.ca][2])

**One important point:** don't tell Lovable to literally copy the Instagram pages or download/use their copyrighted photos. Tell it to take **visual inspiration** from the references and use licensed/placeholder imagery until you have the client's actual event assets.
